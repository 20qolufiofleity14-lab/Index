📖 定義・基本
甲状腺腫（goiter）の定義
  • 成人：甲状腺重量 > 30 g（超音波容積 > 18–20 mL）
  • 小児：甲状腺容積 > 体表面積（m²）× 10 mL
    年齢・体格による正常範囲あり → 超音波で容積評価が標準
  • 触診による七条分類が臨床の基本（②タブ参照）

診察時の注意点
  • 患者を座らせ、頸部をやや前傾させてから触診開始
  • 後屈させながら唾液を飲んでもらう → 甲状腺が動く
  • 両葉の硬さ・均一性・圧痛・結節の有無を確認
  • 血管雑音（bruit）の聴診 → 陽性ならバセドウ病を強く示唆
七条分類は触診評価の標準化のためのツール。超音波で容積を定量評価することと組み合わせて使用する。

👁️ 甲状腺腫に伴う全身所見（疾患特異的サイン）
バセドウ病特有
  • 眼球突出（exophthalmos）
    バセドウ眼症 → 眼球後脂肪組織増殖
  • 眼瞼後退（Graefe徴候）
  • 甲状腺血管雑音（bruit）特異的
  • 前脛骨粘液水腫（稀）
  • 手指振戦・頻脈・体重減少
橋本病
  • 甲状腺腫は硬め・ゴム様・分葉状
  • 機能低下症状：倦怠感・浮腫・便秘・寒がり
  • 若い女性に多い（女:男 = 5–10:1）
  • 橋本脳症（稀）：精神症状・意識障害
甲状腺癌（危険なサイン）
  • 嗄声（反回神経麻痺）
  • 嚥下困難
  • 頸部リンパ節腫脹
  • 結節の急速増大
  • 石様硬・周囲固定

🧪 検査ワークアップ
基本セット（甲状腺腫初診時）
  • TSH（最初の一手 ← 感度最高）
  • FT4・FT3（TSH異常時に追加）
  • 抗TPO抗体（anti-TPO）橋本病・バセドウ
  • 抗サイログロブリン抗体（anti-Tg）橋本病
  • TRAb（TSH受容体抗体）バセドウ確定診断
  • サイログロブリン（Tg）癌フォロー・術後
追加検査（状況別）
  • カルシトニン 結節あり・家族歴 → 髄様癌除外
  • CEA 髄様癌の腫瘍マーカー
  • CRP・ESR・血算 亜急性甲状腺炎（CRP↑↑）
  • RET遺伝子 髄様癌 → MEN2スクリーニング
TSAbはバセドウの活動性評価に有用（TRAbより機能的）。甲状腺癌術後のTg測定は再発モニタリングの標準。
🖥️ 超音波（US）— 甲状腺腫評価の中核
必ず確認する項目
  • 甲状腺容積（長径×横径×前後径×π/6）
  • エコー輝度・均一性
    低エコー：橋本病・悪性疑い　高エコー：腺腫様
  • 結節の有無・個数・サイズ
  • 血流（Doppler）
    バセドウ：全体に血流↑↑（inferno pattern）
  • 頸部リンパ節
悪性を示唆するUS所見（結節）
  • 低エコー（周囲組織より暗い）
  • 微細石灰化（psammoma body）特異的
  • 不整辺縁・境界不明瞭
  • 縦横比 > 1（taller than wide）
  • 血流：結節内血流↑
  • 辺縁不整・被膜外浸潤
良性を示唆するUS所見
  • スポンジ様（多発小嚢胞）ほぼ良性
  • 純粋嚢胞（pure cyst）
  • 等〜高エコー・境界明瞭・整
  • 周辺性石灰化（eggshell）

🌡️ バセドウ病（Graves病）
病態
  • TSH受容体に対する刺激型自己抗体（TRAb/TSAb）→ 甲状腺を持続的に刺激 → 機能亢進＋腫大
診断のポイント
  • 三徴：甲状腺腫＋眼球突出＋頻脈（全部揃わなくても）
  • TRAb陽性 → 確定診断
  • 血管雑音（bruit）→ びまん性腫大 ＋ bruit は本疾患にほぼ特異的
治療（概要）
  • 抗甲状腺薬（MMI / PTU）← まず内科的治療
  • 放射性ヨード（RAI）治療 — 小児では適応慎重
  • 手術（甲状腺全摘 / 亜全摘）
  • βブロッカー（症状緩和）
小児バセドウ：薬物治療で長期寛解を目指す
MMIを2–4年継続 → 約30–40%で寛解。再発率が成人より高い
🧊 橋本病（慢性甲状腺炎）
病態
  • 甲状腺に対する自己免疫性炎症（TPO抗体・Tg抗体）→ リンパ球浸潤 → 甲状腺組織破壊
  • 機能はさまざま：正常機能 → 潜在性低下 → 顕性低下まで段階がある
診断
  • 抗TPO抗体 and/or 抗Tg抗体 陽性 ← 診断の核心
  • エコー：低エコー・不均一・索状パターン
  • 小児：機能低下があれば補充療法を開始
経過
  • 多くは緩徐進行 → 甲状腺機能低下症に移行
  • 一部で橋本脳症（稀）：精神症状・痙攣
  • 癌合併リスク：わずかに↑（MALTリンパ腫も）
機能正常の橋本病 → 治療不要。抗体価の経時的変化より機能（TSH）を追う方が重要。
🔥 亜急性甲状腺炎
病態・特徴
  • ウイルス感染後の肉芽腫性炎症 → 有痛性の甲状腺腫大
  • 甲状腺痛＋発熱＋CRP↑↑ → ほぼ本疾患で確定的
  • 経過：亢進期（甲状腺ホルモン漏出）→ 正常 → 一時的低下 → 回復（自然治癒）
治療
  • NSAIDs（軽症）→ PSL（中〜重症）
  • βブロッカー（亢進症状が強い場合）
  • 抗甲状腺薬は不要（漏出なので）
通常6–12週で自然回復 → 永続的機能低下は5–10%のみ

👶 小児の甲状腺腫：成人と異なる点
疾患頻度（小児特有）
疾患小児での特徴
橋本病最多（特に思春期女児）。多くは無症状
バセドウ病2番目。再発率高く薬物治療を長期継続
甲状腺結節悪性率20–26%（成人の5%より著明に高い）
甲状腺癌乳頭癌が90%以上。リンパ節転移多いが予後良好
先天性甲状腺機能低下症（合成障害型）出生時から甲状腺腫。稀。甲状腺ペルオキシダーゼ変異等
小児の甲状腺結節は成人より積極的にFNAを行う
悪性率が高いため TIRADS のサイズ閾値を下げて検討する施設が多い
⚠️ 悪性を示唆するレッドフラグ
以下があれば積極的に専門医紹介・FNA
  • 嗄声・嚥下困難・呼吸困難（神経・気管・食道浸潤）
  • 頸部リンパ節腫脹（特に硬い・固定）
  • 急速増大（週単位）
  • 石様硬・周囲組織への固定
  • 放射線照射歴（頸部への被曝）
  • 甲状腺癌の家族歴（乳頭癌・MTC）
  • MEN2の家族歴 → RET変異・カルシトニン測定
  • 単発結節 ≥ 1–1.5 cm + TIRADS TR4–5
小児の甲状腺癌（乳頭癌）は転移があっても予後良好。早期手術が推奨される。

🏥 専門医紹介のタイミング
緊急または早期紹介
  • 甲状腺クリーゼ（発熱・頻脈・意識障害）→ 直ちに
  • 悪性レッドフラグあり → 甲状腺外科・耳鼻科
  • 気管・食道圧迫症状
  • Bethesda IV以上 → 外科
待機的紹介
  • バセドウ病：薬物治療中断・副作用（無顆粒球症）・再発
  • 小児バセドウ：RAI・手術選択時
  • 甲状腺癌術後の長期フォロー（腫瘍内科・核医学）
  • MEN2疑い → 遺伝子検査・多発性内分泌腫瘍チーム
  • 先天性甲状腺機能低下症（合成障害型） → 代謝専門
💊 抗甲状腺薬（MMI）の主要副作用と対応
無顆粒球症 最重要
  • 頻度：0.2–0.5%（MMI）
  • 発熱・咽頭痛が出たら直ちに受診
  • WBC・好中球 → 好中球 < 500 → 即入院・G-CSF
  • MMI中止 → PTUへ変更（交差反応に注意）
肝機能障害
  • 軽度のAST/ALT上昇（経過観察）
  • 重篤な場合 → 中止
  • PTUでより頻度高い（重篤な肝障害リスク）
  • 定期的なLFTsモニタリング
その他
  • 皮疹・掻痒感（5–10%）
  • 関節痛・筋肉痛
  • ANCA関連血管炎（PTU）
  • 催奇形性（MMI：第1三半期は注意）
    妊娠初期はPTUが推奨される場合あり
