🧬 遺伝・疫学
  • 遺伝形式：X連鎖性（XL） — 最多の尿素サイクル異常症
  • OTC遺伝子：Xp21.1（酵素：ミトコンドリア内膜）
  • 罹患頻度：約 1/14,000–1/56,000（日本：約 1/22,000）
  • ヘミ接合体男児：通常重症（新生児型）
  • ヘテロ接合体女性：X染色体不活化（ライオン化）で表現型に幅
    無症状〜重症まで。成人後の初発例も多い

📊 NBS（新生児マス・スクリーニング）
  • タンデムマス：血中シトルリン値低下でスクリーニング
  • 感度の限界：女性キャリア・残存活性あり例で偽陰性リスク
  • NBS陽性 → 血漿アミノ酸分析 + 尿中オロト酸 → 確定診断へ
NBS陽性でも症状発現前から治療開始可能（最重要メリット）
🧪 高アンモニア血症の神経毒性機序
NH₃ 毒性の主要機序
  • グルタミン過剰産生（Glu + NH₃ → Gln ↑↑）
    → アストロサイト浮腫（細胞性脳浮腫の主因）
  • TCAサイクル抑制（α-ケトグルタル酸消費）→ エネルギー産生障害
  • 神経興奮毒性（NMDA受容体調節障害）
標的器官と障害
  • 脳：大脳皮質・基底核・脳幹
    白質病変・皮質萎縮・脳浮腫
  • 肝臓：肝機能障害（特に重症例）
  • NH₃ と Gln の組み合わせが最も毒性が高い

🚨 臨床症状（発症形式別）
新生児型（生後24–72時間）
哺乳開始（タンパク摂取開始）後に急速に悪化
出生直後は一見正常 → 急速進行
  • 哺乳不良・嘔吐・活気低下 → 急速に意識障害
  • 過換気（呼吸性アルカローシス）→ 混合性代謝性アシドーシス（後期）
  • 筋緊張低下 → 痙攣 → 昏睡
  • 脳浮腫 → 脳ヘルニア（未治療では死亡）
遅発型（乳児期〜成人）
  • 繰り返す嘔吐・頭痛・意識障害エピソード
  • タンパク嫌い（protein aversion） — 自発的に肉を避ける特徴的
  • 誘因：感染・手術・分娩・高タンパク摂取・バルプロ酸
  • 軽症例：行動変化・認知機能低下のみで長年診断されない
  • 女性キャリア：産褥期・手術後などに初発することが多い
🔬 診断検査と解釈
緊急検査（NH₃上昇確認時）
  • 血漿アンモニア（NH₃） 最優先
    正常: <50 μmol/L（小児）、<110 μmol/L（新生児3日以内）
    採血後は氷上保存・直ちに測定（放置で偽高値）
  • 血漿アミノ酸分析 必須
    グルタミン ↑↑（最も鋭敏）、アラニン ↑、シトルリン ↓↓（OTC特徴）

    ↑↑（OTC欠損の特異的所見） ← CPS1欠損では正常〜低値
  • 血糖・電解質・血液ガス・LFTs・凝固・NH₃

  • OTC遺伝子解析（血液）— 確定・家族診断

⚠️ 高アンモニア血症の鑑別（UCD以外）
新生児期
  • 一過性高アンモニア血症（未熟児）
  • 有機酸代謝異常症（MMA、PA等）
    → 代謝性アシドーシスを伴うことが多い
  • 脂肪酸酸化異常症
  • 肝不全（感染、虚血）
乳児期以降
  • ライ症候群様疾患（薬剤誘発性）
  • バルプロ酸誘発性高アンモニア血症
    → OTC欠損キャリアで特に注意
  • 肝硬変・劇症肝炎
  • 敗血症・ショック（間接的）
有機酸代謝異常との鑑別
  • 有機酸（MMA、PA）：
    代謝性アシドーシス ＋ ケトーシス ＋ NH₃↑
  • UCD（OTC等）：
    アシドーシス軽度（特に初期）＋ 呼吸性アルカローシス
  • 血漿アミノ酸 ＋ 尿中有機酸 ＋ アシルカルニチンで鑑別
🚨 高アンモニア血症は神経学的緊急症 — NH₃ > 150 μmol/L で直ちに治療開始
⏱️ Step 1：即時対応（最初の30分）
① 全てのタンパク摂取を即時中断
経口・経管・経静脈 — 全ルートからのアミノ酸/タンパク停止
ただし 24–48時間を超える中断は筋崩壊（異化亢進）を招くため注意
② 高カロリー輸液（カタボリズム抑制）
GIR 8–10 mg/kg/分 以上（新生児）
10–12.5% ブドウ糖（CVC推奨）＋ 脂肪乳剤 2–3 g/kg/日
インスリン抵抗性があれば少量インスリン併用
③ 中枢静脈路・気道確保の準備
高濃度糖輸液には中心静脈カテーテルが必要
意識障害 → 気道確保・ICU管理へ

🩸 Step 4：血液浄化療法（透析）の適応
透析を強く推奨する場合
・NH₃ > 500 μmol/L
・薬物療法に反応しない or 急速な上昇
・意識障害を伴う（GCS ≤ 12 の目安）
・新生児重症例（> 300–400 μmol/L で早期考慮）
透析モダリティの選択
方法NH₃除去速度推奨場面
CVVHD / CVVHDF中〜高新生児・乳児に推奨
間欠的血液透析（IHD）最高体格が大きい場合に有効
腹膜透析（PD）低（不十分）推奨しない（緊急性が高い場合）
透析開始後も薬物療法は継続
窒素スカベンジャー・アルギニン・高カロリー輸液を並行して継続
📈 Step 5：回復期 — タンパク再開とモニタリング
タンパク再開の目安
  • NH₃ < 100–150 μmol/L が持続
  • 経口摂取または経管投与が可能
  • タンパク中断から 24–48時間を超えないこと
    （筋崩壊による内因性NH₃産生が増加）
  • 再開は少量から（0.5 g/kg/日）→ 段階的増量
急性期NH₃管理目標
目標NH₃：< 100 μmol/L
24時間以内の達成を目指す
できれば ≤ 80 μmol/L まで
NH₃ > 300 μmol/L が持続 →
透析適応を再評価
急性期モニタリング頻度
  • 血漿NH₃：1–4時間毎（治療中）
  • 血糖：1–2時間毎（高カロリー輸液中）
  • 電解質・血液ガス：4–6時間毎
  • 血漿アミノ酸：6–12時間毎（Gln, Arg）
  • 尿量・バランス：1時間毎
🥣 低タンパク食 ＋ EAAサプリメント
タンパク制限の原則
  • 天然タンパクを制限しつつ必須アミノ酸（EAA）を確保
  • アルギニン・シトルリン・システインは条件付き必須化 → 補充が必要
  • 年齢別推奨タンパク量（目安）：

🤒 シックデイ緊急プロトコル
感染・発熱・手術など：急性高アンモニア血症の誘因
異化亢進 → 内因性NH₃産生↑↑ → 急速な悪化
家族への指導内容
  • 食欲低下・嘔吐時：
    タンパク一時中断 ＋ 高カロリー補充（糖質・脂質）を優先
  • 経口摂取不可の場合：直ちに医療機関受診
    → 高カロリー点滴・窒素スカベンジャーIV開始
  • スカベンジャー内服は原則継続
    （嘔吐で内服困難 → 救急受診の基準）
  • 緊急時カード（Emergency Protocol Card）を常携
受診の目安（患者家族への基準）
嘔吐が続く ／ 意識が変わった ／ 普段より眠い
→ 迷わず受診・血漿NH₃緊急測定
🧪 カルニチン補充・栄養管理
カルニチン補充
  • 窒素スカベンジャー（特にブフェニル®）使用中はカルニチン消耗
  • L-カルニチン：50–100 mg/kg/日（1日2–3回）
  • 血漿遊離カルニチンでモニタリング（目標：正常域）
栄養管理の重点
  • 十分なカロリー摂取（成長に必要な基礎カロリー ＋ 10–20%）
  • 必須脂肪酸（DHA/EPA）補充を考慮
  • ビタミン・ミネラル：EAA製剤に含まれるが定期確認
成長モニタリング
  • 身長・体重：毎受診時（成長障害の早期発見）
  • 体重増加不良 → カロリー不足 or 慢性的NH₃上昇の可能性
  • 学校・保育園への食事指示書の準備

🚨 代謝失代償のサイン（受診・入院基準）
緊急受診の基準
  • 嘔吐が続く ／ 食事が取れない状態が続く
  • いつもと様子が違う（ぼんやり・眠い・ぐったり）
  • 頭痛の訴え（遅発型患者）
  • 意識レベルの変化
  • スカベンジャー内服が続けて飲めない
NH₃上昇時の対応フロー
NH₃ 100–200 μmol/L → タンパク一時中断・高カロリー補充・外来または入院観察
NH₃ > 200 μmol/L → 入院・IV窒素スカベンジャー開始（③急性期治療タブ参照）
NH₃ > 500 μmol/L → PICU転送・透析準備
⛔ 絶対禁忌薬剤 — バルプロ酸（VPA）
バルプロ酸（VPA）はOTC欠損症に絶対禁忌
OTC欠損患者（キャリア女性を含む）に投与すると致死的な急性高アンモニア血症を誘発する
VPAによるNH₃上昇機序（複合的）
  • CPS1直接抑制（尿素サイクル全体の起点を阻害）
  • L-カルニチン消耗 → 脂肪酸β酸化障害 → 異化亢進
  • ミトコンドリア機能障害（補酵素A欠乏）
  • タンパク異化亢進によるNH₃産生増加
臨床的注意点
  • OTC欠損（診断前の）患者にてんかんとしてVPA投与 → 急性脳症として発症した報告あり
  • 無症状キャリア女性でもVPA使用で急性発作が誘発される
  • てんかん合併時：VPA以外の抗てんかん薬を選択
    （レベチラセタム、ラモトリギン等）
  • 処方時のアレルギー・禁忌欄への登録・お薬手帳への記載
⚠️ 注意を要するその他の薬剤・状況
薬剤・状況リスク対応
バルプロ酸（VPA）急性高NH₃血症（致死的）絶対禁忌
ステロイド大量投与タンパク異化亢進 → NH₃↑可能な限り避ける。使用時は頻回NH₃測定
L-アスパラギナーゼNH₃産生増加使用時は密接モニタリング
カルモスチン（BCNU）肝毒性 + NH₃上昇慎重投与
長時間絶食・術前処置異化亢進 → NH₃↑最低限の絶食時間・IV補液（glucose）を早期開始
感染症・高熱異化亢進 → 急性増悪早期の高カロリー補給、NH₃頻回測定
分娩・産褥期（女性）女性キャリアで急性発作の誘因周産期専門家との連携・NH₃監視体制
♀️ 女性キャリアの管理
女性キャリアの特徴
  • X染色体不活化（ライオン化）の偏りで表現型に幅
    無症状〜重症型まで多様
  • 「タンパク嫌い」「食後の不調」が唯一の訴えのことがある
  • 成人後（妊娠・出産・感染後）に初めて高NH₃症で発症する例多数
管理・フォロー
  • OTC遺伝子変異確認 ＋ タンパク負荷試験
  • 空腹時NH₃・血漿Gln測定（定期）
  • 妊娠・分娩時：産科と事前プロトコル共有
    分娩前後のNH₃モニタリング計画
  • VPA等禁忌薬剤の徹底周知
  • 軽〜中等症には慢性期スカベンジャー療法を考慮
家族内のキャリアスクリーニングと遺伝カウンセリングが重要
🏥 肝移植（根治療法）
肝移植はOTC欠損症に対して根治的
尿素サイクル機能を正常化 → NH₃管理の制限から解放
適応・タイミング
  • 重症OTC欠損（新生児型・食事療法/薬物療法で管理困難例）
  • 急性発作を繰り返す例
  • QOL・コンプライアンスに著しく影響する例
  • タイミング：重篤な神経学的障害発生前が理想
    脳への不可逆的ダメージが生じる前に移植を
移植後の変化
  • タンパク制限を大幅に緩和可能
  • 窒素スカベンジャー中止可能
  • 既存の神経学的障害は回復しない（移植前の管理の重要性）
ドナー選択に注意
家族内ドナー（血縁者）は必ずOTCキャリア検査を先行
義務的キャリアや軽症発現キャリアをドナーにしないこと
📈 長期予後・アウトカム
新生児型（重症・男児）
  • 初回NH₃発作の重症度と持続時間が予後を左右
  • 早期診断・迅速治療でも神経学的後遺症が残ることあり
  • 肝移植後は代謝的には安定
  • NBS前の時代：高い死亡率（現在はNBSで予防可）
遅発型・管理良好例
  • 良好なNH₃管理下では通常の知的発達が可能
  • 食事制限・服薬の長期維持が課題
  • 急性発作のリスクは生涯持続（誘因に注意）
  • Ravicti®等の新薬でQOL改善期待
神経学的後遺症のリスク因子
  • 初回NH₃ピーク値（高値ほど不良）
  • NH₃ > 300 μmol/L の持続時間
  • 脳浮腫の程度（MRI所見）
  • 急性発作の繰り返し
NH₃ 1000 μmol/L超・長時間持続
→ 重篤な後遺症・死亡リスク高
