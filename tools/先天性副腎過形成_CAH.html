♀️ 46,XX 患者（女児）の臨床像
出生時（古典型）
  • 外陰部男性化（外性器異常） — 診断の端緒
    Prader分類（詳細は②タブ参照）
  • 内性器は正常女性型（子宮・卵巣あり）
  • SWでは副腎クリーゼ（2〜4週）も合併
未治療・治療不十分の場合
  • 性早熟（偽性早熟）
  • 骨年齢促進 → 最終身長の低下
  • 成人期：月経不順・多毛・にきび（NC型）
♂️ 46,XY 患者（男児）の臨床像
出生時（古典型）
  • 外性器は一見正常（男性化しているので見かけ上は正常）
  • SW型では生後7〜21日に副腎クリーゼ発症
    哺乳不良・嘔吐→ショック。NBS結果前に発症することも多い
  • SV型：幼児期の陰茎肥大・陰毛早発（見逃されやすい）
未治療の場合
  • 偽性性早熟 → 骨年齢促進 → 最終身長低下
  • 精巣副腎残余腫瘍（TART）— 成人男性に多い
  • 精子形成障害（TART・過剰GC抑制）
🔬 新生児マス・スクリーニング（NBS）
スクリーニング法
  • 測定項目：17-OHP（乾燥濾紙血）
  • 採血時期：生後4–6日（哺乳開始後）
  • 判定：出生体重別カットオフ値を使用

🔍 副腎クリーゼの認識
典型的な経過（SW型男児）
  • 生後7–21日：哺乳量減少・嘔吐・活気不良
  • 体重増加不良 → 体重減少
  • 脱水進行 → 循環不全 → ショック
  • 痙攣（低Na血症による）
  • 低血糖（コルチゾール欠乏）
即時採血（治療前に！）
  • 血清 Na・K・Cl・CO₂（最優先）
  • 血糖（低血糖チェック）
  • 血漿コルチゾール（治療前ベースライン）
  • 17-OHP（治療前サンプル）
  • レニン・アルドステロン
採血と治療は並行して行う
検査結果を待って治療開始を遅らせない
臨床的にクリーゼを疑えば即時HC投与

🚨 治療モニタリング上の警告サイン
治療不足のサイン（17-OHP↑・アンドロゲン↑）
  • 骨年齢が暦年齢より 2歳以上先行
  • 身長速度が過剰（成長スパート早期）
  • 陰毛早発・陰茎肥大（男児）・陰核肥大（女児）
  • にきび・体毛増加
骨年齢促進が続くと最終身長が予測より著明に低くなる
→ HC用量・投与タイミングの見直し
治療過多のサイン（クッシング徴候）
  • 成長率の低下・成長障害
  • 体重増加・満月様顔貌
  • 皮膚線条・骨密度低下
  • 高血圧・低K（FC過多）
成長速度低下は過多の最早期サイン
「良いコントロール = 適切な成長速度」
🧬 DSD管理・性別適合・外科的対応
性別適合（46,XX CAH）
現代コンセンサス：女性として育てる
46,XX CAHの性自認は通常女性 → 女性として育てることを推奨
  • Prader Ⅰ–Ⅱ：外科的手術が不要な場合も多い
  • Prader Ⅲ–Ⅴ：外陰部形成術（clitoroplasty, vaginoplasty）を検討
    手術時期については施設・家族・本人との十分な協議が必要
  • 早期手術 vs 後期手術：現在も国際的に議論中
  • 思春期前に心理的サポートを開始
家族・患者への説明の要点
  • 内性器は正常女性（子宮・卵巣あり）→ 妊娠の可能性
  • 外性器の外観は治療・手術で改善可能
  • 生涯にわたるホルモン補充が必要
  • 多職種チーム（内分泌・泌尿器外科・心理・遺伝・看護）で対応
🤰 妊娠・出産とCAH
CAH患者の妊娠管理
  • 妊娠前：17-OHP管理の最適化・遺伝カウンセリング
  • HC継続（コルチゾールは胎盤で不活性化されるため胎児影響少）
  • FC継続（必要な場合）
  • 妊娠中は用量増加が必要な場合あり
  • 分娩時：HC「ストレスカバー」（50–100 mg/m² IV）
出生前治療（Prenatal DEX）
デキサメタゾン（DEX）母体投与（現在は倫理的に制限あり）
目的：胎児の外性器男性化を予防（CAH家族歴のある場合）
問題点：胎児のDEX曝露による長期影響不明
→ 現在は施設倫理委員会承認下で限定的にのみ実施
次子のリスク（両親ともキャリアの場合）
  • 次子が46,XXで古典型CAH：25% × 50% = 12.5%
  • 着床前診断・出生前診断の選択肢を遺伝カウンセリングで提示
🏫 移行医療・成人管理
小児→成人移行（15–18歳目安）
  • 成人内分泌科と連携を早期に開始
  • 思春期以降：HC用量を成人量（10–12 mg/m²/日）へ調整
  • 成人女性：月経・妊娠・婦人科的問題への対応
  • 成人男性：TART・精子形成の評価
成人CAHの課題
  • アドヒアランス：生涯服薬 → 怠薬リスク
  • 代謝合併症：高血圧・肥満・糖尿病リスク
  • 骨粗鬆症：GC長期使用 → DXA定期評価
  • 精神的健康：疾患・外性器への受容、QOL
📈 長期予後と成長への影響
最終身長への影響
  • 古典型CAH：未治療・治療不十分 → 骨年齢促進 → 最終身長 −5〜−10 cm
  • 適切な管理下 → ほぼ遺伝子身長に近い最終身長が期待できる
  • 治療開始が遅れた場合：GnRHa（LHRHa）で思春期を遅らせ身長を確保する選択肢
妊孕性
  • 女性：適切な管理下で妊娠可能（SW型でも報告あり）
  • 男性：TART、副睾丸精子通過障害 → 妊孕性低下リスク
早期診断（NBS）＋ 適切なHC/FC管理 ＋ 多職種チーム
→ 通常に近い身体発育・生活・妊孕性が期待できる
🔍 非古典型（NC）CAH — 遅発型・軽症型
臨床像・発見契機
  • 陰毛早発（premature pubarche）
  • 女性：多毛・にきび・月経不順・PCOS様
  • 男性：思春期早発・にきび
  • 不妊検査で偶然発見
  • 家族歴（古典型の兄弟姉妹）からスクリーニング
診断
  • 基礎17-OHP：2–10 ng/mL（borderline）
  • ACTH刺激試験（250 μg IV）
    → 刺激後17-OHP > 10 ng/mL → NC-CAH確定
  • CYP21A2遺伝子解析
治療方針
  • 全例治療が必要とは限らない
  • 治療適応：
    成長への影響（骨年齢促進）
    症状（多毛・月経不順）
    妊孕性に影響する場合
  • HC用量は古典型より少ない
    5–7.5 mg/m²/日 程度
