予測身長・成長曲線ビジュアルツール

両親の身長から目標身長（TH）／現在のSDスコアから予測成人身長を自動計算し、日本人標準成長曲線（2000年基準値）上に描画します。 ver6

目標身長（TH：target height / 両親中央身長）

男児 TH = (父の身長 + 母の身長 + 13) / 2 女児 TH = (父の身長 + 母の身長 − 13) / 2
  • 13cmは日本人成人の男女平均身長差に由来します（(父+母)/2 ± 6.5cm と同じ式）。
  • THはあくまで期待値（中央値）で、実際の成人身長はこの前後にばらつきます。本ツールは成人身長のSD（男5.83cm・女5.25cm）を用いて ±1SD・±2SD の範囲を併記しています。
  • 両親のいずれかが低身長の場合、その親自身に疾患（家族性低身長・骨系統疾患・SHOX異常など）が隠れている可能性があり、THだけで「遺伝的だから正常」と判断しないよう注意します。

身長SDスコアと予測成人身長

SDスコア = (実測身長 − 同性同月齢の平均身長) / SD 予測成人身長 = 成人平均身長 + 現在のSDスコア × 成人のSD
  • いわゆるSDトラッキング法です。「現在のSDスコアをそのまま維持して成人に至る」という仮定に基づきます。
  • 思春期前の児では概ね妥当ですが、思春期の開始時期が早い／遅い場合には大きく外れます（早発では過大評価、遅発では過小評価）。
  • より精密な予測にはBayley-Pinneau法・TW法など骨年齢を用いた予測が必要です。本ツールは骨年齢を扱いません。
  • 参照値は日本小児内分泌学会「2000年度乳幼児身体発育調査・学校保健統計調査」に基づく標準値です。

骨年齢を用いた予測（本ツールの方法と、その限界）

予測成人身長 = 現在の身長 ÷ (骨年齢時点の標準身長 ÷ 成人平均身長)
  • 「その骨年齢の時点で、成人身長の何%に達しているか」で割り戻す比率法（%成人身長法）です。日本人標準成長曲線の中央値から%を求めています。
  • ご指摘の「思春期に入ると伸びが止まる」点は、この方法では自動的に織り込まれます。例えば女児で骨年齢14歳なら標準曲線上の身長は156.0cm・成人158.1cmなので到達率98.6%、つまり残りは約2cmしか予測されません。骨年齢が進んでいるほど残存身長が小さく出ます。
  • グラフのオレンジ点線は「骨年齢が暦年齢と同じ速さで進む」と仮定して、標準曲線の形に沿わせた軌道です。思春期後半で自然にプラトーになります。
  • 限界（重要）：これは Bayley-Pinneau法（BP法）ではありません。BP法はGreulich-Pyle骨年齢に対する「成人身長到達率表」を用い、しかも骨年齢が暦年齢より進んでいるか遅れているかで別の表を使います。本ツールは単一の中央値曲線しか用いていないため、成熟の早い児・遅い児では系統的な誤差が生じます。
  • 集団の中央値曲線は多数の児の思春期スパートを平均したものなので、個人のスパートの鋭さは平滑化されています。思春期直前の児では残存身長を過小評価しやすい傾向があります。
  • 成長ホルモン治療の適応判定・治療効果判定など公式な最終身長予測にはBP法・TW法（RUSスコア）など検証済みの方法を使用してください。本ツールの値は外来での説明・おおよその目安に留めてください。
  • 骨年齢の評価法（GP法／TW2-RUS法／日本人標準）によって骨年齢そのものが1歳前後ずれることがあります。どの方法で読んだかを併記して解釈してください。
  • 骨年齢は1点あれば予測できます。Bayley-Pinneau法・TW3法・RWT法いずれも「骨年齢1点＋その時の身長＋暦年齢」で計算する設計で、連続撮影は前提ではありません。本ツールも同じで、予測値は1点のみから算出されます（グラフのオレンジ点線の"形"だけはΔBA/ΔCA＝1と仮定して描いており、到達点の数値はこの仮定に依存しません）。
  • 連続撮影が必要になるのは予測のためではなく骨成熟速度（ΔBA/ΔCA）を評価するためです。GnRHアナログ治療の効果判定、思春期早発症、先天性副腎皮質過形成のコントロール評価、GH治療中の骨年齢の追い越し確認などが該当します。骨年齢を2点以上入力すると本ツールもΔBA/ΔCAを表示します（目安：約1.0＝相応、>1.3＝促進、<0.7＝遅延）。
  • 1点であることの本当のリスクは「読みの誤差」です。GP法の読者間差は±0.5〜1歳が通常で、これがそのまま予測誤差になります。本ツールは骨年齢を±1歳ずらした場合の予測幅を自動表示するので、家族には点ではなく幅で説明してください。
  • 骨年齢を用いない Khamis-Roche法（身長・体重・両親中央身長のみ）という選択肢もあります。レントゲンが撮れない・撮る適応が乏しい場面で有用です。
撮影時の暦年齢の扱い（重要）
骨年齢は「何歳の時に撮ったか」とセットでなければ意味を持ちません。本ツールでは骨年齢を測定行そのものに入力する方式にしており、その行の暦年齢と身長を使って計算します。
・予測式に入るのは撮影時の身長と骨年齢だけです（暦年齢は式には入りません）。したがって12歳2か月時の骨年齢14歳なら、12歳2か月時点の身長で割り戻すのが正しく、その後に伸びた身長を使ってはいけません。
・暦年齢は「進んでいるか／遅れているか」の判定に使われ、解釈（思春期早発の疑い、体質性遅発の疑い）と、本来ならBayley-Pinneau法のどの換算表を使うかを決めます。12歳2か月で骨年齢14歳なら +1.8年の促進で、BP法なら accelerated の表を使う場面です。
・骨年齢が古い撮影（最新の身長測定から6か月以上前）の場合は警告を表示します。骨成熟の速度は一定とは限らないため、その間に変化している可能性があります。
2つの予測値の読み分け
・暦年齢法 > 骨年齢法（骨年齢が進んでいる）→ 思春期早発・肥満・CAHなどによる骨成熟促進の可能性。今の身長が高くても最終身長は低くなりうる、という説明に使えます。
・暦年齢法 < 骨年齢法（骨年齢が遅れている）→ 体質性思春期遅発症、GH分泌不全、甲状腺機能低下症など。伸びしろが残っている、という説明に使えます。
・両者が近い → 成熟のペースは年齢相応。

成長速度（growth velocity）

  • 直近2点から年間成長速度（cm/年）を算出し、同年齢の平均的な成長速度（標準曲線の傾き）と比較表示します。
  • 測定間隔が短いと誤差が大きくなるため、6か月以上（できれば1年）あけた2点での評価を推奨します。

肥満度・BMI

肥満度(%) = (実測体重 − 標準体重) / 標準体重 × 100
  • 伊藤式：性別・身長別標準体重（幼児は二次式、学童以降は身長帯ごとの三次式）。
  • 村田式：性別・年齢別・身長別標準体重（5〜17歳、y = a×身長 + b）。学校健診で広く使われます。
  • BMIのSDスコアはLMS法（日本人小児のL・M・S係数）で算出しています。
出典：日本小児内分泌学会「日本人小児の体格の評価に関する基本的な考え方」および同学会公開の成長曲線描画ファイル（plotgrowthchart v1.21, 伊藤善也ら）に収載された標準値・係数を使用しています。

低身長として精査を検討する目安

  • 身長が −2.0SD以下（特に −2.5SD以下は成長ホルモン治療の適応判定の対象）
  • SDスコアが経時的に1.0SD以上低下している（成長曲線を下向きに横切る）
  • 年間成長速度が同年齢の平均を明らかに下回る（学童期でおおむね 4cm/年未満）
  • 予測成人身長がTH−2SDを下回る（＝家族性で説明できない低身長）
  • 低身長＋不均衡（上下肢比の異常）、SGA性低身長、思春期の遅れ、頭痛・視野障害などの中枢症状を伴う
  • 体重増加不良・便通異常・慢性疾患の症状を伴う（栄養・消化器・腎・心疾患・甲状腺機能低下症など）
スクリーニング検査の一例：血算・生化学・電解質・IGF-1・FT4・TSH・骨年齢（左手X線）・尿検査。必要に応じてカリオタイプ（女児）、抗TG/TPO抗体、セリアック病スクリーニング、GH分泌刺激試験など。

高身長として精査を検討する目安

  • 身長 +2.0SD以上、かつTHから大きく上方に乖離している
  • 成長加速を伴う（思春期早発症、甲状腺機能亢進症、GH過剰）
  • マルファン症候群、ソトス症候群、ホモシスチン尿症、クラインフェルター症候群などを示唆する身体所見

フォロー終了（経過観察オフ）の目安

  • 身長SDスコアが −2SD以内で安定し、かつTH±2SDの範囲内を推移している
  • 年間成長速度が年齢相応で、成長曲線に平行して伸びている（SDのチャンネルを保っている）
  • 基礎疾患のスクリーニングが陰性で、身体所見・発達に異常がない
  • 思春期が年齢相応に進行し、最終身長に到達している（成長速度 <1cm/年、骨端線閉鎖）
家族への安全網（safety net）の説明
「今のところ、ご両親の身長から予想される範囲で順調に伸びています。学校の身体計測の記録は必ず母子手帳やアプリに残しておいてください。①1年間で背がほとんど伸びない ②成長曲線のカーブを下向きに横切ってきた ③頭痛や吐き気、視野の異常が出た ④体重が減ってきた——このいずれかがあれば、次の健診を待たずに受診してください。」
